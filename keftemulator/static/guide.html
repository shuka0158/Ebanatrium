Keftemulator User Guide

📋 Overview

Keftemulator is a comprehensive OSINT (Open Source Intelligence) platform that aggregates data from 40+ public sources including usernames, emails, domains, IPs, phone numbers, Georgian business registry, court documents, and more. It combines SpiderFoot-style recursive pivoting with a beautiful graph interface and map visualization.

Key Features:

  • Recursive entity discovery with depth control (0-5 levels)
  • Visual graph of relationships between entities
  • Map view for geographic data
  • Case management for grouping related scans
  • Monitors for scheduled searches with change notifications
  • 40+ integrated data sources including Georgian registries

🚀 Quick Start

1. Start a Scan
Enter a target (username, email, domain, IP, phone, name, company) → Select depth (0-5) → Choose modules → Click "Scan"

2. Explore Results
Graph shows all discovered entities and relationships. Click nodes to see details. Map displays geographic data.

3. Create Cases
Group multiple scans together. Cases merge and deduplicate findings across scans.

4. Monitor Changes
Set up monitors to run scans on a schedule and get notified of new findings via ntfy.sh.

📊 Depth & Pivoting

Depth controls how many recursive levels of discovery Keftemulator performs:

Depth Description Use Case
0 Only direct lookups on the target (no pivoting) Quick checks, single entity details
1 Direct target + discovered entities Standard investigation, 5-20 min
2 Up to 2 levels of recursion Deep investigation, 10-30 min
3+ Deep recursive search Complex networks, may hit rate limits, 30+ min
💡 Tip: Start with depth 1 for faster results. Increase depth if you need to discover hidden connections.

🔍 Running a Scan

Step 1: Enter Target

Type the target in the search box. Keftemulator auto-detects the type (email, domain, IP, etc.). You can also manually specify the type.

Step 2: Choose Depth

Default is 1. Use 0 for quick checks, 2+ for deeper investigation. Higher depths take longer and may trigger rate limits.

Step 3: Select Modules

By default, all available modules run. Click "Select Modules" to customize which sources to query.

Step 4: Click Scan

The scan starts immediately. You'll see a live entity counter. The graph updates in real-time.

During Scan

  • Graph shows discovered entities and edges
  • Results list shows new findings as they arrive
  • Logs tab shows module activity and errors
  • Click "Stop" to halt the scan (you can resume later with Cases)

📈 Graph View

The graph shows all discovered entities as nodes and relationships as edges.

Node Types & Colors

  • Blue: Usernames, accounts
  • Green: Domains, IPs, networks
  • Pink: Emails, breach data
  • Orange: Companies, organizations
  • Purple: Images, files
  • Yellow: Phone numbers, names

Interactions

  • Click node: See details, related data, links
  • Drag nodes: Reposition graph
  • Scroll/pinch: Zoom in/out
  • Search results list: Click result to highlight node in graph

🗺️ Map View

Displays geographic data: IP locations, DNS records, VPN detection, server locations.

  • Click map marker to see details
  • Zoom to explore regions
  • Markers show IP geolocation, ISP, and confidence

📁 Cases

Group multiple scans together for complex investigations involving multiple targets.

Create a Case

  • During or after a scan, click "Add to Case"
  • Enter case name (e.g., "Investigation: Company XYZ")
  • Add multiple scans to the same case

Case View

  • Cases tab shows all your cases
  • Click a case to view merged results
  • Entities are deduplicated across scans
  • Add notes to track findings
  • Export as JSON, CSV, or HTML report

⏱️ Monitors (Scheduled Scans)

Automatically run scans on a schedule and get notified when new findings appear.

Create a Monitor

  • Click Monitors tab → "New Monitor"
  • Enter target (username, company, etc.)
  • Set interval (hours): 1, 6, 24, etc.
  • Select modules to run
  • Optionally assign to a Case

Notifications

  • Set ntfy.sh topic in Settings for push notifications
  • Receive alerts when new entities are discovered
  • View monitor event history
💡 Tip: Use monitors to track companies, usernames, or domains over time. Catch new website mentions, leaked credentials, or domain changes.

⚙️ Settings

API Keys

Add API keys for enhanced functionality:

  • Shodan: IP/port scanning, device intelligence
  • VirusTotal: File/URL reputation, domain/IP analysis
  • Hunter.io: Email finding and verification
  • HIBP: Breach database (free tier available)
  • GitHub Token: Higher rate limits, private repo scanning
  • NumVerify: Phone number validation
  • AbuseIPDB: IP abuse reports
  • CARTO: Map tiles API key
  • IntelX: Intelligence database search
  • URLScan: Higher rate limits for URL scanning
  • ntfy.sh topic: Enter your ntfy.sh topic for monitor notifications

Advanced Settings

  • Max Depth: Default recursion depth (0-5)
  • Max Entities: Stop scan after discovering N entities (default 400)
  • Threads: Concurrent module workers (default 8)
  • Tool Timeout: Max seconds per tool execution (default 600)

🛠️ Tools Management

External tools required by some modules:

  • Sherlock/Maigret: Username search across 50+ sites
  • TheHarvester: Email and subdomain enumeration
  • PhoneInfoga: Phone number OSINT
  • ExifTool: Image metadata extraction
  • SpiderFoot: Full-featured OSINT framework
  • Recon-ng: Certificate and DNS reconnaissance

Click "Install All Missing" in Settings to auto-install missing tools.

💡 Tips & Best Practices

  • Start Small: Begin with depth 1 and expand if needed. Higher depths take longer and may hit rate limits.
  • Use Cases: Group related scans in Cases for easier analysis and deduplication.
  • Check Logs: Click "Logs" tab to see what each module found and any errors.
  • Export Results: Export scans/cases as JSON (structured data), CSV (spreadsheet), or HTML (report).
  • API Keys: Add keys for better coverage. Free tiers work but have rate limits.
  • Monitor Targets: Use monitors to track high-interest targets over time.
  • Respect robots.txt: Keftemulator respects robots.txt and rate limits.
  • Legal Use Only: Use Keftemulator for authorized investigations, security research, and OSINT. Respect local laws and data protection regulations.

⚖️ Legal & Ethical Guidelines

⚠️ Important: Keftemulator is designed for authorized OSINT research, security investigations, and pentesting within legal boundaries.
  • Only search public data: No scraping private profiles, bypassing authentication, or accessing non-public APIs.
  • Respect robots.txt: All web crawling respects website guidelines.
  • No biometric identification: Face recognition and mass identity linking are not supported.
  • Comply with local law: Data protection laws vary by jurisdiction. Use Keftemulator responsibly.
  • Authorized access only: Only investigate targets you have authorization to research.
  • Respect privacy: Don't publish or misuse personal information discovered during OSINT.

🔧 Troubleshooting

Scan stops or finds few results

  • Check API key configuration in Settings
  • Some modules require API keys to work
  • Verify internet connection
  • Check logs for rate-limit or timeout errors

    • Graph is empty or slow

    • Reduce depth to 0-1 for faster results
    • Lower Max Entities limit in Settings
    • Try a simpler search target (single username rather than complex data)

    Modules show as unavailable

    • Click "Install All Missing" in Settings
    • Some modules require external tools (Sherlock, ExifTool, etc.)
    • Check Settings → Tools for installation status

    No notifications from monitors

    • Enter ntfy.sh topic in Settings
    • Click "Test Notification" to verify setup
    • Monitors run on a schedule (check interval in case details)
